# Icon Placeholder

This directory should contain the following icon files:

- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels) 
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can create these icons using any image editor. Suggested design:
- Background: Soft gradient (light blue to purple)
- Icon: Simple meditation/wellness symbol (🧘‍♂️ or similar)
- Style: Rounded, modern, friendly

For now, you can use any 16x16, 32x32, 48x48, and 128x128 pixel PNG images as placeholders.

Alternatively, you can use online tools like:
- favicon.io
- canva.com
- figma.com

To create proper icons for your Chrome extension.
